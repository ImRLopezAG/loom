Loom connects a TypeScript schema and function definitions to PostgreSQL. A backend owns its schema, migrations, authorization, and generated client contract. React applications consume that contract without importing server code.

## Start with the data

Read the [quickstart](/quickstart), then define your [schema](/authoring/schemas). Use native oRPC procedures, database-read/write middleware for transactions, and bare procedures for external work.

## Before deployment

Loom is under development. The packages in this workspace are private and are not a published installation target. Review the [operating limits](/operations/limits) before evaluating a deployment.
