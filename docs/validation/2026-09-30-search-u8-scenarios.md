# Relational search: scenario coverage audit

All 130 supported scenarios in the accepted plan have owning assertions across the executed layers below. IDs are requirements, not test counts: one differential test exercises several IDs, and some scenarios require complementary type/runtime/browser proofs. Characterization failures and expected negative compiler diagnostics are explicitly identified. No skipped database/cloud test counts as acceptance.

- **T**: TS7 positive source (no error suppressions), real compiler negatives, and installed generated declarations: `packages/tests/types/search-{schema,contracts,generated}.test-d.ts`; `packages/e2e/integration/packed-search-generated.test.ts`.
- **CACHE**: Native upstream limitation characterization and approved guards: `packages/tests/unit/search-options.test.ts`, `search-cache-guards.test.ts`; finite/live browser observers and packed generation.
- **CONTRACT**: Standard Schema, graph identity, input budgets, private capabilities, public OpenAPI and descriptor composition: `packages/tests/unit/search-contracts.test.ts`, `search-compiler.test.ts`, `search-http-errors.test.ts`.
- **RELATIONS**: Real Neon direct/to-many/M2M, policy-scoped junctions, aliases and four edges: `packages/e2e/integration/search-relations.test.ts`.
- **PAGES**: Real Neon differential finite traversal: `packages/e2e/integration/search-pagination.test.ts`; authenticated key parsing/comparisons: `packages/tests/unit/search-cursor.test.ts`.
- **TRANSACTIONS**: Real Neon invocation guards, count barrier, finite concurrent writes, HTTP/WebSocket and Effect output checks: `packages/e2e/integration/search-transactions.test.ts`; `packages/tests/unit/search-executor.test.ts`.
- **GENERATION**: Installed package generation, watcher field/relation edits, codec change and unmount compiler checks: `packages/e2e/integration/packed-search-generated.test.ts`; watcher failure/retry: `packages/e2e/integration/dev-watcher.test.ts`.
- **COMPONENTS**: Real Neon repeated mounts, private/dependency contexts and cursor scope: `packages/e2e/integration/search-components.test.ts`; mounted/detached ownership and retained roots/children/junctions are checked in that same search test.
- **LIVE**: Real Neon external commits, current loaded windows, count, auth revocation and idle transaction checks: `packages/e2e/integration/search-live.test.ts`; `packages/tests/unit/search-live.test.ts`.
- **BROWSER**: Installed native finite/live/suspense options: `packages/e2e/browser/search-finite.test.ts`, `search-client.test.ts`; provider lifecycle/reconnect and slow-client regressions.
- **SSR**: Installed package concurrent identity prefetch/dehydrate/hydrate and nonblocking server live render: `packages/e2e/fixtures/packed-search-ssr.ts`, invoked by packed generated test. Independent Next/Start builds: `packages/e2e/integration/packed-frameworks.test.ts`.
- **CLOUD**: Required runner: `packages/e2e/cloud/run.ts`; real packed Functions/search: `cloud/search.test.ts`. Durable redacted receipt: `2026-09-30-search-u8-neon-receipt.json`.
- **DOCS**: Root docs build/typecheck and generated executable snippets: `apps/docs/examples/search-*.{ts,tsx}`, `examples/loom/{search,contracts/search,functions/search}.ts`; authoring/search and clients/pagination; public SearchBudgets JSDoc.

## Evidence and limits

See the [U8 validation receipt](2026-09-30-search-u8-hosted-acceptance.md) for commands, pass counts, review fixes and hosted target. U1-U7 receipts retain their phase-specific proof. The selected type boundary is generated `connection.client`/`connection.rpc`; recreating upstream utilities is a documented fixed-output limitation. Arbitrary cache writes and intentionally colliding custom keys are outside the guarantee.
