# Installed Turbo metadata contract — unapplied source proposal

This proposal is anchored to committed `2b65387ec6293980828274202d10d2471ec00386`, supervisor `e5f42c9bb6cf2d0360d84b974f38ffa8784c6387bb6da8e4679bfe89214097d0`. It is not an implementation, guard change, runtime authorization or causal fix. Both current remote receipts show dependency/file_35 regular=true, nlink=2, size=753, bound=1048576 and only link_count_not_one. They establish this preflight refusal; they do not establish installation origin or the state of prior uninstrumented runs. The original integration workload remains NOT RUN.

## Exact proposed boundary

`proposal.patch` changes only the artifact supervisor at three locations: the finite refusal predicate selection for dependency/file_35; a new private `installed_turbo_metadata(report)` reader with no caller-supplied path or bound; and the single corresponding check_pins read plus explicit package name/version validation. `regular_bytes` itself and every other caller remain unchanged. The new reader always uses `ROOT / "node_modules/turbo/package.json"` and 1 MiB. There is no generic allow-hardlinks flag or node_modules-prefix exception. Future implementation would require only the corresponding consumed freeze supervisorSha256 update and immutable archive/history; those changes are not made here.

This one read admits any positive link count, including one. It rejects zero links, nonregular files, symlink leaf, out-of-range size, observed identity/link/mode/size/timestamp drift, changed pathname binding, changed resolved parent and changed content between two reads. It does not unlink, replace, chmod, copy, reinstall or mutate the installed dependency or its aliases. Owned source, artifacts, backups, dist, configuration, trace, restoration and publication retain single-link requirements.

## Descriptor and byte stability

The exact parent resolves inside checkout/node_modules and its resolved location is checked again after reading. Parent symlinks inside that tree are allowed because this is installed metadata, not a new policy for owned artifacts. A leaf lstat rejects symlinks; open uses O_RDONLY | O_NOFOLLOW | O_NONBLOCK so a raced FIFO cannot wait for a writer before type rejection. fstat must identify a regular file with nlink >= 1 and size in [0, 1 MiB]. The before-lstat and opened descriptor must agree on device, inode, full mode, link count, size, mtime_ns and ctime_ns.

Two reads use the same descriptor, each at most 1 MiB + 1 bytes, with a seek between them. Before/middle/after fstat identity tuples must be identical; both byte lengths must equal initial size and fit 1 MiB. SHA-256 of the two observed byte sequences must agree. Final pathname lstat must match the original descriptor tuple, and the resolved parent must match its initial value. A replacement symlink/nonregular/zero-link file or ordinary size/write/link drift therefore refuses rather than returning evidence from an altered binding. Atime is excluded because reading can change it.

These comparisons detect observed drift, not arbitrary adversarial concurrency. They cannot authenticate external writers, lock all hardlink aliases, prove filesystem history, stop later mutation after close, or prove which package executable a future shell resolves. Repeated same-file reads are not an independent trusted content digest. The existing frozen install, fixed checkout/job, pinned package identity, original task graph and later runtime provenance are complementary evidence, not a universal immutability guarantee.

## Writer assumptions and identity

The operational assumption is a completed frozen install followed by no further install, package retarget or dependency-content write during the supervisor's metadata read and original workload. The diagnostic itself makes no dependency writes. A positive nlink says multiple directory entries refer to an inode; it does not say they are immutable or identify their paths. Serial CI steps constrain this job's own commands, not external processes, package-cache writers or malicious actors. No authenticated immutability, lock lease or exclusion against such actors has been demonstrated. Violation observed during reading fails; undetected or subsequent changes remain a stated limitation, not successful verification.

Parsing remains duplicate-key-rejecting unique_json. The proposed gate requires a dictionary with exact name `turbo` and version `2.11.6`; it does not treat that self-description as a supply-chain signature. Existing BASE hashes, live package/build/config hashes, exact root script `turbo run test:integration`, e2e `bun test ./integration`, task cache=false and dependsOn=[^build], and exact reviewed trace-only passThroughEnv comparison remain unchanged. No trusted metadata-content hash is invented from the failing run or from a local dependency probe. Missing actual build/root/lineage evidence later still yields incomplete.

## Fixed refusal semantics and privacy

The same report container, eight fixed stages and 38 fixed file IDs remain. Only `(dependency, file_35)` evaluates link validity as positive and uses a new fixed predicate string `link_count_not_positive` for zero; every other identity retains `link_count_not_one`. This explicit finite predicate change is part of the proposal for review. A valid nlink=2 must not be labelled a failed predicate when this reader rejects a different property. No regular_bytes guard is selected or changed by those metadata identities.

Initial regular/link/size refusal uses the existing primary file_type_or_bound and R3's established-container unavailable marker plus containment of the entire optional call. Observed descriptor detail replaces unavailable only after existing range/schema and <=1024-byte serialization validation. Open/lstat/resolve failures may have no descriptor detail. New fixed reasons dependency_parent_invalid, dependency_symlink, dependency_identity_changed and dependency_read_changed describe stability failures without publishing paths, hashes, inode numbers, payloads, environments or exception messages. Identity/hash comparisons remain internal; existing final report and publication bounds are unchanged. Zero-link descriptor metadata can publish the new fixed predicate; malformed/out-of-range optional metadata remains unavailable.

Two reads add at most one extra MiB+1 of I/O and a second bounded buffer compared with the old single read. This is a disclosed diagnostic cost, not a cache-policy or deadline change. The accepted data remains <=1 MiB; no trace/file/aggregate/receipt/publication budget is widened. The existing 30-minute job and all test deadlines remain intact.
